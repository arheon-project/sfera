# Катящаяся сфера

Веб-приложение для расчёта и 3D-визуализации зоны молниезащиты методом катящейся сферы (СП РК 2.04-103-2013).

Доступ к рабочей версии выдаётся по приглашению.

- 3D-сцена, план, разрезы, проверка оборудования;
- импорт подложек из AutoCAD (DXF), распознавание подписей «М1», «E1»;
- экспорт DXF для AutoCAD LT, PDF-отчёт, Excel, PNG, сохранение проекта в .json.

Вся страница — один файл `index.html`, работает в браузере без сервера.
